# Dola 多账号登录态管理器

基于 DrissionPage 的多账号登录态管理工具。每个账号拥有独立的浏览器数据目录（相当于 Playwright 的独立 `BrowserContext`），登录态持久化保存在本地，下次启动直接选择账号即可进入已登录状态。

登录流程（Google SSO + Dola）完全由用户手动在浏览器窗口中完成，本脚本只负责维护账号池、开窗、保持浏览器运行、复用持久化登录态。

## 功能

- 账号池管理：新增 / 删除 / 选择账号
- 每个账号独立 `user_data_path` + 独立调试端口，cookie / localStorage / session 完全隔离
- 登录态持久化到本地 `profiles/` 目录，重启电脑后依然有效
- 浏览器窗口保持开启，可同时运行多个账号
- 无需任何登录自动化，全程手动登录，安全可靠

## 依赖

- Python 3.8+
- DrissionPage（已随本文档安装，如迁移环境：`pip install DrissionPage`）

## 快速开始

```bash
python dola_accounts.py
```

启动后直接显示账号池：

```
==============================================
   Dola 多账号登录态管理器 (DrissionPage)
==============================================

账号池:
  （空，按 N 添加第一个账号）

输入序号打开对应账号 | N 新增账号 | D 删除账号 | 0 退出（浏览器保持开启）
```

## 使用说明

| 操作 | 命令 | 说明 |
| --- | --- | --- |
| 打开账号 | 输入账号序号 | 用该账号的持久化登录态启动浏览器并打开 Dola，直接进入已登录状态 |
| 新增账号 | `N` | 输入备注名 → 弹出浏览器窗口 → 手动完成 Google SSO 与 Dola 登录 → 回终端按回车确认，账号加入池中 |
| 删除账号 | `D` | 按提示输入序号，可连同浏览器数据（登录态）一并删除 |
| 退出 | `0` | 退出脚本，所有浏览器窗口保持开启，登录态已保存 |

## 文件结构

```
dola/
├── dola_accounts.py    # 主脚本
├── config.json         # 配置（Dola 网址、浏览器路径）
├── accounts.json       # 账号池（自动维护）
└── profiles/           # 各账号浏览器数据目录（登录态，自动创建）
```

## 配置

`config.json`（首次运行自动生成）：

```json
{
  "dola_url": "https://dola.me",
  "browser_path": "",
  "extension_path": ""
}
```

- `dola_url`：Dola 登录页地址，如网址不同请修改
- `browser_path`：Chrome 可执行文件路径，留空则自动查找（注册表 / PATH）。使用 Chrome 系浏览器（Edge、360 等）时需填写
- `extension_path`：Chrome 插件目录（需含 `manifest.json`）。所有账号浏览器每次启动时统一加载，留空则不加载

## 工作原理

1. 每个账号创建时分配一个独立的用户数据目录（`profiles/<账号>/`）和调试端口（从 9223 起递增）
2. 浏览器以 `--user-data-dir` 指向该目录独立运行，登录产生的 cookie / localStorage 全部落盘持久化
3. 再次打开同一账号时：浏览器仍在运行则直接连接，已关闭则用相同目录重新启动，登录态自动恢复
4. 脚本退出不影响浏览器，登录态始终保留在本地

## 常见问题

**Q: 打开账号后还是未登录状态？**
首次添加账号后未按回车确认，或登录时未完成 Google SSO 全流程。重新用该账号打开浏览器完成登录即可。

**Q: 提示找不到浏览器？**
未检测到 Chrome，请在 `config.json` 的 `browser_path` 填写浏览器可执行文件路径（如 Edge：`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`）。

**Q: 端口被占用报错？**
删除账号时未一并删除浏览器数据、且旧浏览器仍在运行时可能出现。关闭对应账号的浏览器窗口后重试，或重启电脑。

**Q: 插件没生效？**
插件是在浏览器启动时加载的，已打开的浏览器需要先关闭（或删除账号时一并删除数据）后重新打开才会加载插件。插件以加载方式注入，不会写入账号数据目录。
